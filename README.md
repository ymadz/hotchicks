# Hot Chicks website

A responsive restaurant landing page based on the supplied Stitch prototype, brand assets, menu image, and hero footage.

## Stack

- React and TypeScript for reusable sections and future menu or ordering interactions
- Vite for a small, fast build and simple hosting
- Native CSS for the brand styling and lightweight animation
- Local MP4 with a poster image for the hero footage

## Run locally

```bash
npm install
npm run dev
```

For a production build, run `npm run build`.

The menu starts with three featured mains and can expand to six. Mains can be customized with heat and extras. Sides and drinks can be added directly, and every item has a quantity control. The local bag does not submit orders or take payments. Location and opening hours were not present in the supplied materials. Add verified details and an ordering destination before publishing.
