## Overview

I created this project as an independent design and development initiative to explore how a Hot Chicks restaurant website could look and work. It gives visitors a quick way to explore main chicken dishes, sides, and drinks through a visual menu. The site also includes a local order bag so users can choose heat levels, extras, and quantities before checkout is connected.

## Features

- Video hero section with a responsive layout
- Centered navigation and official Hot Chicks logo
- Animated menu ticker
- Main chicken menu with collapsed and expanded views
- Heat-level selection for main dishes
- Side chicks and cool drinks menu sections
- Quantity controls for menu items
- Local order bag with item removal and totals
- Responsive layouts for desktop and mobile
- Reduced-motion support
- Hand-drawn food illustrations and background accents

## My Role

I designed and built the website interface, including the page layout, responsive styling, hero section, menu cards, hand-drawn visual system, and local order interactions. I also integrated the supplied logo, food images, and video assets and tested the layout at desktop and mobile widths.

## What I Learned

- How to structure a small React site with reusable menu data
- How to build an order customization flow with local state
- How to make a video hero responsive without hiding the main content
- How to create a hand-drawn visual language with CSS and SVG paths
- How to handle mobile browser styling differences, including iOS link colors and emoji substitutions
- How to check responsive layouts for overflow and readability

## Challenges

- Keeping large display typography readable over moving food footage
- Balancing expressive doodles with menu readability
- Making the menu and order dialog work across different screen sizes
- Avoiding default iOS link and emoji styling on mobile
- Keeping the order bag useful while checkout and payment services are not connected

## Future Improvements

## Installation

1. Clone the repository or download the project.

2. Open the project folder in a terminal.

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown by Vite, usually `http://localhost:5173`.

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Project Status

In development. The website is a working frontend prototype. The local menu interactions work, but online checkout, payments, restaurant details, and deployment are not connected yet.
